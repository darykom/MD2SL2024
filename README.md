# MD2SL 2024  
My assignments for the [II level Master in Data Science and Statistical Learning](https://www.md2sl.unifi.it/), University of Florence, 2024.  

---  
## Block I: Data Science Bootcamp  

### Mathematics and Statistics for Data Science  
**Optimization** – Solved optimization problems covering unconstrained, constrained, and stochastic algorithms, with detailed solutions provided.  
**Numerical Calculus and Linear Algebra** – Practical exercises in Numerical Calculus and Linear Algebra covering fundamental topics such as errors and machine arithmetic, linear systems (including LU decomposition and SOR method), and least square approximation.  
**Probability and Stochastic Processes** – Slides describing D.P. Capel's Bayesian super-resolution algorithm, applied to image estimation from multiple low-resolution inputs as a practical demonstration of probability concepts.  
**Statistical Inference** – Solved exercises in Statistical Inference covering key topics such as likelihood and Bayesian estimation, sampling distributions, confidence intervals, and fundamental probability concepts.  
**Statistical Modeling** – Regression analysis on two distinct datasets: New York restaurant data for price prediction (linear regression) and Italian company data for foreign direct investment propensity (logistic regression).  

### Algorithmic Foundations and Programming Skills  
**Algorithms and Programming in Python for Data Science** – Development in Python and algorithmic complexity analysis for several functions processing a dataset concerning primary school temporal contact data. Visualization of the temporal interactions is also required and implemented.  
**Algorithms and Programming in R for Data Science** – Simulation of a large student dataset from 100 schools and its comprehensive statistical analysis using R are the core objectives, including data manipulation and various visualizations of grade distributions and demographic characteristics.  
**Machine Learning** – Exploration of core Machine Learning concepts through practical application of linear regression, utilizing the California Housing Price Dataset for demonstrations and analysis.

## Block II: Core Courses  

### Statistical Learning for Data Science
**Statistical Learning** - Slides detailing the development and execution of Monte Carlo methods, exemplified by an analysis of the Least Median of Squares (LMedS) robust regression algorithm.  
**Geo-spatial Data analysis** - Spatial analysis of current GDP patterns and related factors in African states, incorporating historical slave trade data.  
**Network Data analysis** - Network analysis of Marvel comic character partnerships, exploring key insights from centrality measures, community detection, and Stochastic Block Models.

### Supervised and Unsupervised Learning
**Advanced Machine Learning** - See SVM part in the "Health Analytics" assignment  
**Deep Learning** - Convolutional Neural Network (CNN) training for image recognition on the CIFAR-10 dataset, focusing on architecture design, optimization, and overfitting management. 


### Complex Systems
**Text Mining and NLP** - Slides concerning Natural Language Processing (NLP) insights focusing on the attention mechanism and Transformer models applied to prediction tasks.  
**Complex Network Analysis** - Slides about two copula-based methods for network reconstruction and generation.   
**Complex System Analysis** -  Slides on Complex System Analysis exploring Julia and Mandelbrot sets. Topics include their dynamic properties and computational rendering via escape time and inverse iteration methods.  

### Decision Theory for Data Science
**Bayesian Causal Inference** - Analysis of the effects  on unemployed individuals from JOBS II data using Bayesian methods, featuring a Beta-Binomial model for re-employment probability inference and a Normal-InverseGamma model for the causal analysis of depression, with MCMC (Gibbs sampler) for inference on SATE e PATE.  
**Analytics in Economics and Business** - Causal inference exploiting Double Machine Learning, leveraging tree-based models like Bagging and Random Forest, comparing the results with the traditional approach with instrumental variables, applied to the effect of slaves trade on GDP of modern African States.  

### Hands-on labs
**Hands-on Python for Data Science** - 
CelebA dataset metadata processing and exploration with Pandas. 
Followed by Convolutional Neural Network (CNN) implementation and training in PyTorch for grayscale and color image super-resolution on CelebA facial images.

## Block III: Elective Courses

### Data Science for Business  
**Time Series Analysis** - Time Series Analysis modeling an acyclic series on potato production (with ARIMA model) and a seasonal series concerning average monthly maximum temperature (with SARIMA model), including stationarity verification, model diagnostics, and forecast accuracy evaluation for both.  
**Financial Risk Management** - Analysis of multidimensional financial time series, isolating stationary log-returns, computing univariate VaR and ES using historical and parametric methods, and modeling multivariate dependence with Gaussian and t-Student copulas.  

### Data Science for Health
**Health Analytics and Data-driven Medicine** - Survival Analysis by specialization of Ranking Support Vector Machines into Survial SVMs, with experimental verification on a simple Breast Cancer dataset.

## Thesis  
**Federated Human Activity Recognition** - This study proposes a Human Activity Recognition system using smartphone sensor data, where RNN and LSTM models encode motion into embeddings for MLP classification, extended with federated learning via Flower and validated on the DAGHAR dataset.
